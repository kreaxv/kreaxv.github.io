Tailscale Subnet Router гэж юу вэ?

kreaxv February 14, 2026

Tailscale Subnet Router гэж юу вэ? (Бодитоор юунд хэрэгтэй вэ)

Tailscale-ийг ихэвчлэн “WireGuard-тай хялбар VPN” гэж ойлгодог. Гэхдээ нэг том асуудал байдаг.

👉 Таны сүлжээнд байгаа бүх төхөөрөмж дээр Tailscale суулгаж болдоггүй.

Жишээ нь:

  • Принтер
  • Камер
  • NAS
  • Router
  • Smart TV
  • IoT төхөөрөмжүүд

Эдгээр нь VPN client суулгах чадваргүй. Гэхдээ та алсаас хандахыг хүсдэг.

Энд Subnet Router гарч ирдэг.

Subnet Router = Сүлжээний хаалга

Subnet Router бол Tailscale-д холбогдсон нэг төхөөрөмж бөгөөд таны дотоод LAN-ийг бүхэлд нь Tailscale-д “оруулж” өгдөг.

Өөрөөр хэлбэл:

Таны laptop (гадаад)
        ↓
Tailscale network
        ↓
Subnet Router (гэрт байгаа Raspberry Pi / Server)
        ↓
192.168.0.x бүх төхөөрөмж

Тэгээд л боллоо. Камер дээр Tailscale суулгах шаардлагагүй.

Яагаад Exit Node биш вэ?

Хүмүүс их андуурдаг.

Exit Node

  • Интернет траффик дамжуулна
  • Байршил нуух, geo unblock хийхэд ашиглана

Subnet Router

  • Зөвхөн дотоод LAN руу нэвтрүүлнэ
  • Гэрийн сүлжээ рүү алсаас холбогдоход ашиглана

Давуу тал

  • Дотоод серверээ public болгох шаардлагагүй
  • Port forwarding хэрэггүй
  • Dynamic IP асуудал алга
  • Камер / NAS / Printer бүгд алсаас ажиллана
  • Нэг төхөөрөмж л Tailscale суулгахад хангалттай

Ямар төхөөрөмж тохиромжтой вэ?

Хамгийн common:

  • Raspberry Pi
  • Home server
  • NAS
  • Router дээрх Linux
  • Docker host

24/7 асаалттай байхад л хангалттай.

Linux дээр Subnet Router хийх алхам

1. Tailscale суулгана

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Login хийнэ.

2. IP forwarding асаана

Router шиг ажиллуулахын тулд kernel-д packet дамжуулах эрх өгнө.

echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

3. Дотоод сүлжээг advertise хийх

Жишээ: таны LAN = 192.168.0.0/24

sudo tailscale set --advertise-routes=192.168.0.0/24

4. Admin console дээр зөвшөөрнө

Tailscale Admin → Machines → Subnets → Approve

Одоо юу болсон бэ?

Гадаадаас:

ssh 192.168.0.5
http://192.168.0.10
\\192.168.0.3

Шууд ажиллана.

Public IP, port, firewall, DDNS юу ч хэрэггүй.

SNAT гэж юу вэ?

Default-оор LAN төхөөрөмжүүд таны laptop-ыг биш,
Subnet router-ыг харна.

Тиймээс лог дээр:

192.168.0.2 → camera

гэж харагдана.

Хэрэв жинхэнэ IP хадгалах шаардлагатай бол SNAT-ийг унтрааж болно (advanced setup).

Хэзээ ашиглах ёстой вэ?

  • Гэрийн сервер алсаас ашиглах
  • NAS руу аюулгүй хандах
  • Камер харах
  • Smart home удирдах
  • Cloudflare Tunnel-ээс илүү энгийн setup хүсэх үед

Дүгнэлт

Subnet Router бол Tailscale-ийн хамгийн underrated feature.

VPN биш.
Port forward биш.
Reverse proxy биш.

Зүгээр л:

👉 “Гэрийн сүлжээгээ интернэт дээр гаргахгүйгээр алсаас ашиглах” арга.
